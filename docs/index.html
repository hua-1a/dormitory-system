宿舍管理系统 DORMITORY MANAGEMENT SYSTEM

面向校园场景的一体化宿舍管理平台：楼栋、房间、床位、入住与报修全流程数字化管理。

6功能模块
3宿舍楼栋
108房间
260学生

功能一览

覆盖宿舍管理核心场景，六个模块相互联动，数据全流程闭环。

首页看板

统计卡片（学生 / 楼栋 / 房间 / 床位 / 入住率）+ ECharts 图表（楼栋入住、性别分布、报修状态）+ 近期入住动态

学生管理

增删改查、学号 / 姓名搜索、性别筛选、分页展示

宿舍楼栋

楼栋增删改查、入住率进度条直观展示

房间管理

房间新增 / 删除、启用 / 停用、按楼栋筛选

入住管理

办理入住 / 办理退宿，自动更新床位占用并留痕

报修管理

报修提交、状态流转（待处理 → 处理中 → 已完成）

技术栈

主流前后端分离技术组合，工程结构清晰、易于二次开发。

前端

工具

主要接口

后端提供统一的 REST API，返回结构化的 JSON 数据。

方法路径说明
POST/api/login登录
GET/api/dashboard/stats首页看板统计
增删改查/api/students学生管理
增删改查/api/dormitories楼栋管理
增删改查/api/rooms房间管理
GET/api/rooms/options可入住房间
POST/api/checkins办理入住
POST/api/checkins/checkout办理退宿
增删改查/api/repairs报修管理

运行环境要求

项目可在本机完整运行，环境要求如下。

JDK 8+（本机实测 JDK 19 可运行）
Maven 3.6+（IDEA 自带 Maven 也可）
MySQL 5.7+ / 8.0
Node.js 16+、npm 8+
